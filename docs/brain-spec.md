# 大脑电路规范（玩家自定义扩展）

状态：玩家自定义大脑是设计稿，暂未实现。4 个内置 v1 大脑已在 X Layer 流片（TapeID 1.2.271～4.2.271），游戏默认通过 `src/evaluators/tapeout.js` 调用链上 `eval`；`src/evaluators/local.js` 保留为离线模拟。

本文规定：玩家自己设计、在 TapeOut 流片的电路 NFT，满足什么条件才能作为大脑出战。

## 1. 扩展点

引擎只通过 evaluator 接口调用电路，不关心电路来源：

```js
evaluate(circuitId, input) → Promise<0 | 1>
```

接入玩家电路时，只需新增 `src/evaluators/tapeout.js`，在里面调用 TapeOut 合约的 `eval`。计分、智子干扰、读心、界面都不改。

## 2. 接口版本

### v1：1 位输入（当前内置）

| 输入 | 含义 |
|---|---|
| bit 0 | 对方上一轮动作 |

1 位输入的电路只有 4 种行为，所以 v1 只用于内置大脑，不开放给玩家。

### v2：3 位输入（玩家扩展用）

| 输入位 | 含义 |
|---|---|
| bit 0 | 对方上一轮动作 |
| bit 1 | 对方上上轮动作 |
| bit 2 | 我方上一轮动作 |

- 输出：1 位，1 = 交流，0 = 打击。
- 输入编码：`input = 对方上一轮 | (对方上上轮 << 1) | (我方上一轮 << 2)`，取值 0～7。
- 历史不足时补 1（视为交流），和 v1 第 1 轮默认输入一致。
- 所有动作都用纠正后的值（读心识破干扰后的真实动作），这样读心才能切断猜疑链。

v2 共 2⁸ = 256 种大脑。真值表可以记成一个 8 位数，第 i 位是输入为 i 时的输出：

| 大脑 | 真值表 | 说明 |
|---|---|---|
| #1 执剑人 | `0xAA` | 只看 bit 0 |
| #2 逆行者 | `0x55` | bit 0 取反 |
| #3 拯救派 | `0xFF` | 恒 1 |
| #4 清理者 | `0x00` | 恒 0 |
| 宽容执剑人（示例） | `0xEE` | 对方连续两轮打击才还手 |

4 个内置大脑在 v2 下行为不变，引擎可以统一按 v2 运行。

## 3. 准入检查

玩家选择电路出战前，系统逐项检查，任一项不合格就不能参赛，界面要写明原因。

| 检查项 | 做法 | 不合格原因 |
|---|---|---|
| 接口宽度 | 读取电路元数据：3 位输入、1 位输出 | 宽度不符 |
| 纯组合电路 | 只能用 `eval` 调用；需要 `step` 的电路（含 LATCH）拒绝 | 有内部状态，相同输入可能输出不同，违背“透明思考” |
| 输出只有 0/1 | 输入 0～7 各 eval 一次 | 输出越界 |
| 确定性 | 每个输入 eval 两次，结果必须相同 | 结果不一致 |
| 时限 | 每次 eval 在规定时间内返回 | 电路过大，会拖慢对局 |

规则：

- 不做自动修正。输出越界就直接拒绝，不要把 2 当成 1 处理。
- 检查通过后缓存真值表，对局中查表，不必每轮调用链上 eval。`eval` 是只读 view 调用，不消耗 Gas，所以检查本身没有成本。
- 对局中再加一道保险：evaluator 返回非 0/1 值时，判该方违规负，不继续对局。当前引擎只校验输入，输出校验要在实现扩展时补上。

## 4. 链与钱包

- 链：X Layer。TapeOut 已适配 X Layer，目前还在测试阶段。
- 钱包只做只读操作：请求账户地址，读取该地址持有的电路 NFT。不签名，不发交易，不动用玩家资产。
- 列表里每个电路都显示准入结果，比如“✓ 可出战”或“✗ 输出不是 0/1”。

风险：TapeOut 合约在测试阶段仍可升级，正式封印（seal）前，`eval` 的行为或接口可能变化。所以准入结果和缓存的真值表都要记录检查时间，以及合约版本或区块高度。

## 5. 对局规则不变

- 出战电路在对局中保密：提交电路 ID 的哈希承诺，赛后公开。链上电路是公开的，如果对局中暴露了 ID，对手就能直接查出这个大脑。
- 智子干扰仍然永远替换成 #4 清理者（恒 0）。
- 读心仍然是用被读方原本的电路重新计算本轮。

## 6. 已确认的链上接口

从 TapeOut 前端代码和本项目的流片交易确认（2026-10-03）：

- 每个 processor 有自己的 Circuits 合约（ERC-721，电路号就是 tokenId）。本项目在 X Layer 上是 `0x2503025c0355a005a60cd93c971e4e816456c8bd`。
- `eval(uint256 id, bytes inputs) view returns (bytes)`：组合电路，免费只读调用。
- `step(uint256 id, bytes state, bytes inputs) view returns (bytes newState, bytes outputs)`：含时序单元的电路。
- `circuitInfo(uint256 id) view returns (uint32 nIn, uint32 nOut, uint32 nState, uint32 gateCount)`：读出接口宽度和时序单元数。`nState > 0` 表示含 LATCH，准入时拒绝。
- `ownerOf(uint256 id)`：电路持有者。
- 输入输出按小端位序打包成 bytes：第 1 个字节的 bit0 是 IN0。v2 接口的 3 位输入就是 1 个字节，取值 0x00～0x07。
- 流片时会发出 `TapedOut(uint256 indexed circuitId, address indexed author, uint32 gateCount, uint32 nState)` 事件，可以用它扫描某个地址流片过的电路。
- TapeID 格式：`电路号.链代码.处理器编号`，X Layer 链代码为 2。
