游戏规则

1. 你是谁，你要做什么

你代表一个三体文明，和另一个文明连续相遇若干轮。目标是总分比对方高。你只需要做两件事：

  1. 开局前，选一个大脑电路出战。对局中它会自动替你行动。
  2. 对局中被打击时，决定要不要花 1 分读心。

2. 四个大脑电路

每轮电路的输入是对方上一轮的动作，输出是你本轮的动作。第 1 轮默认对方交流过。电路相同输入一定得到相同输出，它自己永远不会撒谎。

这 4 个电路已经在 X Layer 上通过 TapeOut 流片（TapeID 1.2.271～4.2.271）。对局中每一次计算、每一次读心，都是在链上调用电路的 eval 算出来的，任何人都可以复算。

电路对方上轮交流对方上轮打击性格
#1 执剑人交流打击你不动我不动，你打我必还手
#2 逆行者打击交流反着来
#3 拯救派交流交流永远相信善意
#4 清理者打击打击见光就打

3. 每轮怎么计分

一句话：一起交流双赢，互相打击双输，偷袭的人占便宜，被偷袭的人吃亏。

情况你对方
都交流33
你打击，对方交流50
你交流，对方打击05
都打击11

单看一轮，打击总能多拿分；可如果大家都打击，所有人都只剩 1 分。这就是黑暗森林。

4. 智子干扰

每轮每一方都有一定概率（开局时设定的干扰率）被智子操控，大脑临时换成 #4 清理者，打出一次并非本意的打击。干扰对双方是对称的，你和对方每轮各自独立抽签。

  • 你自己被干扰时，界面会当场提示你：你知道自己的电路，本来就能推断出来。你没法替自己辩解，只能等对方读心还你清白。
  • 对方有没有被干扰，你看不到，赛后才公开。

5. 读心

被打击时，你可以花 1 分读心：系统用对方原本的大脑重新计算这一轮。

  • 算出来是交流，说明是智子干扰：对方这一轮改回交流，按真实动作计分，读心费退还。
  • 算出来还是打击，说明对方本性如此：扣你 1 分，比分不变。

对方的大脑在对局中保密，所以你要猜：这次打击是智子干的，还是遇到了清理者？

6. 例子

以下例子都打 6 轮。例 A、B：双方都选 #1 执剑人，第 3 轮对方被智子干扰。

例 A：你选择忍下，猜疑链开始

轮你对方得分发生了什么
1交流交流3 : 3正常
2交流交流3 : 3正常
3交流打击0 : 5对方被智子干扰，你没读心
4打击交流5 : 0你的执剑人自动报复
5交流打击0 : 5对方回敬
6打击交流5 : 0你再回敬

总分 16 : 16。一次误会引发了无休止的互相报复。

例 B：你选择读心，猜疑链被切断

轮你对方得分发生了什么
1～2交流交流6 : 6正常
3交流交流（已纠正）3 : 3读心发现是干扰，改回交流，读心费退还
4～6交流交流9 : 9继续合作

总分 18 : 18，双方各多拿 2 分。

例 C：对方本来就是清理者

你选 #1，对方选 #4。第 1 轮你交流、对方打击，你花 1 分读心，结果还是打击。这一轮你得 0 − 1 = −1 分，对方得 5 分。之后你的执剑人会自动还手，再读心也只是白花钱。

例 D：你被智子干扰，对方读心还你清白

双方都选 #1 执剑人，第 3 轮你被干扰。界面会提示“你的大脑被智子操控了”，你没法辩解，只能看对方。

轮你对方得分发生了什么
1～2交流交流6 : 6正常
3交流（已纠正）交流3 : 3你被干扰打出打击；对方读心，发现你是被冤枉的
4～6交流交流9 : 9继续合作

总分 18 : 18。如果对方没有读心，就会变成例 A 那样的猜疑链，16 : 16。

例 E：遇到拯救派，误会只伤一次

你选 #1 执剑人，对方选 #3 拯救派，第 3 轮对方被干扰，你选择忍下。

轮你对方得分发生了什么
1～2交流交流6 : 6正常
3交流打击0 : 5对方被干扰
4打击交流5 : 0你的执剑人自动报复
5～6交流交流6 : 6拯救派从不记仇，合作自动恢复

总分 17 : 17。拯救派不会还手，猜疑链只走一步就断了。代价是它碰上清理者会被一直欺负，见例 F。

例 F：拯救派遇到清理者

你选 #3 拯救派，对方选 #4 清理者，没有干扰。你每轮都交流，对方每轮都打击，6 轮下来 0 : 30。被打击时读心也没用，读出来全是真打击，每次还要扣 1 分。所以，选拯救派就是在赌对手善良。

例 G：执剑人遇到逆行者

你选 #1 执剑人，对方选 #2 逆行者，没有干扰。

轮你对方得分
1交流打击0 : 5
2打击打击1 : 1
3打击交流5 : 0
4交流交流3 : 3
5～6重复第 1～2 轮1 : 6

总分 10 : 15。双方每 4 轮一个循环，逆行者在循环里占便宜。注意：逆行者的打击都是本意，读心只会白花钱。

例 H：清理者遇到执剑人

你选 #4 清理者，对方选 #1 执剑人，没有干扰。第 1 轮你偷袭得手 5 : 0，之后执剑人一直还手，每轮 1 : 1。6 轮下来 10 : 5，你赢了，可总分只有 10。如果双方都选执剑人和平相处，各有 18 分。清理者赢得了对局，却让自己的文明更穷。
